# GitHub 포트폴리오 페이지 만들기

이 저장소는 GitHub Pages를 활용해 나만의 포트폴리오 웹페이지를 만드는 연습 프로젝트입니다.

## 프로젝트 소개

HTML과 CSS를 사용해 간단한 자기소개 포트폴리오 페이지를 만들었습니다.  
GitHub 저장소에 파일을 올리고, GitHub Pages 기능을 이용해 웹페이지로 공개했습니다.

## 사용한 기술

- HTML
- CSS
- GitHub
- GitHub Pages

## 배운 내용

- GitHub 저장소 만들기
- README.md 작성하기
- index.html 만들기
- style.css 연결하기
- Commit으로 수정 기록 남기기
- GitHub Pages로 웹페이지 공개하기
